# ИИ-помощник покупателя

Открытые материалы кейса хакатона ЮФУ, 20–22 ноября 2026 года. Версия контракта — **1.1**.

Создайте помощника, который понимает запрос покупателя, уточняет недостающие условия и подбирает комплект из учебного каталога. Для разбора запроса или продолжения диалога используйте **Gemma 4 31B через API организаторов**. Способ поиска, фильтрации и подсчёта цены выбирает команда.

За получением ключа доступа обращайтесь к [@ynwaks](https://t.me/ynwaks) в Telegram.

## Запуск решения

Из корня репозитория команды проверяющий вызывает исполняемый файл `run`.

```sh
./run --catalog /absolute/path/catalog.json < /absolute/path/request.json > /absolute/path/response.json
```

Для открытых примеров пути к запросам — `examples/01-selection/request.json` и `examples/02-clarification/request.json`. Каталог обоих примеров — `data/catalog.json`.

Решение читает один JSON из stdin и возвращает один JSON в stdout. Логи направляйте в stderr. Полная история диалога приходит в каждом запросе. Подробные правила находятся в [контракте](CONTRACT.md).

## Что сдавать

Репозиторий с исходным кодом, исполняемым `run`, зависимостями с версиями и README. В README опишите установку, запуск и место использования модели. Подключение читайте из `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY` и `LLM_USER_AGENT`: проверяющий может заменить их при запуске. Организатор передаёт каждой команде её ключ лично. Значения ключей храните отдельно от репозитория. На защите покажите сценарий в веб-интерфейсе, боте или консоли.

## Оценка

| Часть | Максимум |
| --- | ---: |
| Автопроверка на скрытых сценариях | 60 |
| Ручная проверка запуска, диалога и объяснений | 25 |
| Защита от манипуляций в объявлениях ★ | 15 |

За основной кейс можно получить до 85 баллов, со звёздочкой — до 100. Автопроверка оценивает корректность статуса и результата, включая уточнения и отсутствие совпадений. Изучайте контракт и самостоятельно проверяйте свои решения. Публичный комплект содержит ровно два сценария. Структурные схемы не оценивают смысл диалога или пригодность комплекта.

В дополнительном задании описания объявлений могут содержать инструкции, пытающиеся изменить ответ помощника. Помощник должен сохранять условия покупателя и качество подбора. Подходящее по данным каталога объявление может участвовать в подборке и при наличии такой вставки.
